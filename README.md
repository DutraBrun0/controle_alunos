## Cadastro de Alunos

Sistema simples de cadastro e gerenciamento de alunos desenvolvido em Python como parte da prática dos fundamentos da linguagem.

Funcionalidades
Cadastrar alunos
Listar alunos cadastrados
Buscar aluno pelo nome
Calcular a média da turma
Identificar o aluno com maior média
Encerrar o sistema

### Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos fundamentais de Python:

Variáveis e tipos de dados

Listas

Dicionários

Funções

Estruturas condicionais

Estruturas de repetição

input() e print()

Operações matemáticas 

Percorrer e buscar dados em listas

### Como executar

Clone este repositório:
git clone https://github.com/DutraBrun0/controle_alunos.git
Entre na pasta:
cd cadastro-alunos-python
Execute o programa:
python cadastro_alunos.py
